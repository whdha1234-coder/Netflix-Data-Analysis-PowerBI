# Netflix Content & Audience Intelligence Dashboard 📊

An interactive Power BI dashboard built as part of data analytics training to analyze Netflix's global catalog, content distribution, ratings, and trends.

## 🚀 Key Features:
- **Data Cleaning & Preparation:** Cleaned and transformed raw data using Power Query.
- **KPIs & Metrics:** Total Shows, Total Directors, Countries, and Ratings.
- **Geographic & Trend Analysis:** Visualizing content distribution across countries and release years.
